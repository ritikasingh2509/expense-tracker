# 💰 Expense Tracker

A simple and user-friendly Expense Tracker built using **HTML, CSS, and JavaScript**.

This project is being built to practice JavaScript fundamentals, DOM manipulation, event handling, and data management while creating a useful real-world application.

## 🚧 Project Status

🛠️ Currently in development.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## ✨ Planned Features

- Add income and expenses
- Calculate total income, expenses, and balance
- Display transactions
- Delete transactions
- Store data using LocalStorage
- Responsive and clean user interface
